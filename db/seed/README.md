# Community Qbit seed

`community-qbits.json` holds 8 public Qbits forged by players of the original mAIgicly game, before the hackathon. They seed the shared Continuum pool so challenges draw on real human-made inventions from the first play.

- Source: the original game's database, Qbits with `visibility = 'public'` only.
- Anonymized: only game fields are kept (name, role, mission, look, parts, fixes, boost, emblem, recipe, mechanism). Player IDs, aliases, stories and images are removed.
- Three developer test entries (TestForkUnit, RecipeTestUnit, FinalConfirmUnit) were excluded because they are not player creations.
- This is pre-existing data, not hackathon work.
